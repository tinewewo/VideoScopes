# VideoScopes

Прибор видеоконтроля для macOS (Apple Silicon): анализирует входящий сигнал с карты
захвата **Blackmagic DeckLink / UltraStudio** или **любой веб-камеры** (AVFoundation)
и показывает измерительные приборы —
**waveform (яркость)**, **RGB parade**, **vectorscope**, **histogram**, а также
гамут-дисплеи **Diamond** (RGB-гамут) и **Arrowhead** (композитный гамут).
Каждый прибор — отдельное окно: включается/выключается, перемещается, меняет размер
и разворачивается на весь экран.

Захват и вся обработка пикселей идут на GPU (Metal). Шейдеры компилируются в рантайме,
поэтому оффлайн Metal-тулчейн не требуется.

---

## Требования

- macOS 13+ на Apple Silicon (разработано/проверено на M2, macOS 15.7).
- Установленный **Blackmagic Desktop Video** (драйвер + `DeckLinkAPI.framework`).
- **DeckLink SDK** распакован локально (для сборки моста захвата). Сборочный скрипт
  ищет заголовки автоматически в `~/Downloads/Blackmagic_DeckLink_SDK_*/.../Mac/include`.
- Command Line Tools или Xcode (нужен `swiftc` и `clang`). Полный Metal-тулчейн **не**
  обязателен — шейдеры компилируются в рантайме.

Если SDK не найден или папка `CaptureBridge/` отсутствует — приложение собирается
в режиме «только тест-генератор» (без захвата), и приборы работают на синтетических
цветополосах.

---

## Сборка и запуск

```bash
cd VideoScopes
./build.sh
open build/VideoScopes.app
```

`build.sh` сам определяет, есть ли DeckLink SDK, и в этом случае компилирует
Objective-C++ мост и включает реальный захват (`-D HAVE_DECKLINK`). Иначе — собирает
тест-режим. Готовый бандл — `build/VideoScopes.app`.

## Использование

- **Source** (панель «Scopes — control») — выбор источника: подключённая карта
  DeckLink, **любая веб-камера / AVFoundation-устройство** (встроенная FaceTime,
  USB- и виртуальные камеры OBS/NDI, Continuity Camera с iPhone) или встроенный
  тест-генератор (75% color bars). При старте по умолчанию выбирается карта, если
  она есть. Первый выбор камеры вызовет системный запрос доступа к камере — нужно
  разрешить (или включить в System Settings › Privacy › Camera).
- Под выбором показывается **детектированный формат** (например,
  `DeckLink · 1920×1080 · v210 10-bit · 1080p59.94`). Формат определяется автоматически
  (format detection) и обновляется при смене сигнала.
- **Instruments** — чекбоксы включения/выключения каждого прибора; кнопка **⤢** рядом
  разворачивает прибор на весь экран. **Show all / Hide all** — все сразу.
- Окна приборов **перемещаются** за заголовок и **меняют размер** за края (нативно).
  Окно **вектроскопа** ресайзится только **пропорционально** (квадрат).
- **Полный экран**: зелёная кнопка окна, кнопка ⤢ в панели, или меню **View → Toggle
  Full Screen** (⌃⌘F) для активного окна.
- **Поверх всех окон**: чекбокс **Keep settings on top** закрепляет панель управления;
  кнопка **📌** в строке прибора закрепляет конкретный прибор поверх всех окон.
- **Шкалы**: waveform и parade — вертикальная шкала 0–100 % слева; histogram —
  горизонтальная шкала 0–100 % снизу; parade и histogram — подписи каналов R/G/B;
  arrowhead — шкала luma слева.
- **Вектроскоп**: 6 основных мишеней 75 % (R, Mg, B, Cy, G, Yl) + 6 промежуточных
  по угловым серединам (R-Mg, R-Yl, Yl-G, G-Cy, Cy-B, B-Mg), линия тона кожи (I-ось)
  лучом из центра к ~11 часам. Переключатель **V/S gain ×1 / ×2 / ×5** (панель
  управления) радиально увеличивает трассу при неизменной графитуле — например ×2
  для таблиц DSC ChromaDuMonde (CDM12: 6 основных + 6 промежуточных цветов под
  Rec.709), где отражающие патчи ложатся в боксы только при удвоенном усилении.
  Текущее усиление показано в углу прибора.
- **Diamond** (RGB-гамут): верхний ромб из (B′, G′), нижний из (R′, G′); чёрное в
  центре, 100 % на остриях; выход за гамут пересекает грань ромба.
- **Arrowhead** (композитный гамут): luma по вертикали, магнитуда цветности по
  горизонтали; наклонные линии — пределы 100 % / 75 % композита.

## Архитектура

```
DeckLink card ──► DLCapture (Obj-C++ мост, IDeckLinkInput)
                     │  колбэк кадра (v210/UYVY) на потоке захвата
                     ▼
              MetalEngine.submit(frame)         (под локом, кольцевой буфер)
                     │  ensureConverted() на главном потоке (раз на кадр)
                     ▼
   convert_uyvy / convert_v210  ──►  sourceTexture (RGBA16F: R'G'B' + luma)
                     │  общий кадр читают все включённые приборы
       ┌─────────────┼─────────────┬─────────────┐
       ▼             ▼             ▼             ▼
   waveform      RGB parade    vectorscope    histogram     (scatter → accum → resolve)
       └─────────────┴─────────────┴─────────────┘
                     ▼
            blit в окно (MTKView), масштаб под размер/фуллскрин
```

Приборы строятся техникой **накопления плотности**: scatter-кернел атомарно
инкрементирует ячейки буфера по каждому исходному пикселю, resolve-кернел
тон-маппит счётчики в трассу и рисует процедурную графитулю. Конвертация кадра
делается **один раз**; выключённый прибор не стоит ничего.

## Поддерживаемые форматы входа

- **v210** (10-бит 4:2:2) и **UYVY/2vuy** (8-бит 4:2:2) — основной путь.
- Колориметрия **зафиксирована на Rec.709** (601/2020 не используются); диапазон — narrow (video).
- RGB-входы пока запрашиваются как YUV (карта конвертирует). Полноценный RGB/HDR — в планах.
